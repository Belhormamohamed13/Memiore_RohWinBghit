\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
\thispagestyle{plain}

This thesis introduces RohWinBghit, a dynamic cross-platform carpooling system tailored for long-distance transport across Algeria's 69 wilayas. The platform mitigates high travel costs and user trust deficits through a multi-tier architecture: a React Native mobile client (Expo SDK 54), an Express.js back-end with PostgreSQL 16 and Redis 7 databases, and a specialized Python FastAPI microservice executing real-time biometric identity verification (KYC) with anti-spoofing and liveness detection. The system features a custom dynamic pricing model and local electronic payments. System validation was executed using an automated Jest suite (147/151 tests passed, yielding a 97.4% pass rate) alongside a standardized System Usability Scale study (SUS = 71.6/100). Elaborated within the regulatory framework of Decree 1275, the business feasibility study confirms the market potential of the startup.

\textbf{Keywords:} Carpooling, Software Engineering, Biometric KYC, PostgreSQL, Mobile payment, Decree 1275.
